SIM-HARDWARE 3D PRO

Ekspor Komponen 3D

Unduh komponen 3D terbaru yang dibuat secara prosedural di proyek ini menjadi file .GLB. Motherboard kini mencakup soket LGA1700, slot DIMM, slot M.2, slot PCIe, VRM, heatsink, port dan detail PCB; CPU, RAM individual, CPU cooler, SSD, VGA, dan PSU memakai builder yang sama dengan tampilan perakitan serta galeri. GLB adalah model 3D, bukan gambar datar. File ini dapat dimuat kembali ke halaman web menggunakan Three.js GLTFLoader atau software 3D seperti Blender.

Petunjuk: letakkan halaman ini di folder utama proyek, sejajar dengan index.html, kemudian buka melalui server lokal sesuai petunjuk README. Koneksi internet diperlukan untuk memuat Three.js dari CDN.

Folder tujuan yang disarankan

Setelah diunduh, pindahkan file GLB ke static/models/ pada proyek web media pembelajaran. Buat folder models jika belum ada.

Contoh pemuatan di halaman Three.js: gunakan GLTFLoader untuk membuka file seperti ./static/models/ram.glb. Model perlu disesuaikan posisi, skala, rotasi, dan titik snap slot pada sistem perakitan.
